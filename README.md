# مواشي البحرين — موقع عرض الخروف الأسترالي

واجهة عربية ثابتة مبنية باستخدام HTML وCSS وJavaScript دون إطار عمل.

## تشغيل الموقع

افتح `index.html` مباشرة، أو شغّل خادماً محلياً من هذا المجلد:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الصفحات والملفات

- `index.html`: صفحة عرض الخروف وتفاصيله.
- `order.html`: نموذج بيانات العميل وخيارات الاستلام والدفع.
- `how-to-order.html`: شرح خطوات الطلب.
- `privacy.html` و`terms.html`: مسودات سياسة الخصوصية والشروط والأحكام.
- `styles.css` و`app.js`: التنسيق والتفاعلات.
- `assets/mawashi-bahrain-logo.jpg`: شعار الشركة المرفق، بعد إعادة تسمية الملف.
- `assets/australian-sheep.jpg`: صورة توضيحية مولّدة لخروف أسترالي.

## ملاحظات مهمة قبل النشر التجاري

- العرض: خروف أسترالي، وزن 15–18 كجم صافي لحم، بسعر 35 ديناراً بحرينياً.
- النموذج يعمل كتجربة واجهة: يتحقق من الحقول ويعرض ملخصاً داخل الصفحة، لكنه لا يرسل الطلب إلى الشركة ولا يخزن بياناته. يلزم ربطه بخادم أو قناة استقبال معتمدة قبل استقبال طلبات حقيقية.
- اقتراحات العناوين تعتمد خدمة Photon وبيانات OpenStreetMap، وتتطلب اتصال إنترنت. يمكن إدخال العنوان يدوياً إذا لم تظهر اقتراحات.
- سياسة الخصوصية والشروط والأحكام مسودتان توضيحيتان، وينبغي مراجعتهما واعتمادهما من الشركة قبل النشر.
- حساب التحويل المعروض هو: `BH23BBKU00100000412297`.
- أزيل شريط الإعلان من أعلى جميع الصفحات. أضيف تنبيه بأن صورة الخروف توضيحية، وزر النموذج يعرض ملخصاً تجريبياً بدلاً من الإيحاء بأن الطلب أُرسل.
- تأكد من أن السعر ومواصفات الوزن والتوصيل مطابقة لما تقدمه الشركة فعلياً قبل الإعلان.
- لا تضمن التعديلات قبول الإعلان؛ راجع سياسات Snap الحالية وتأكد من إمكانية إثبات ادعاءات الوزن والتوصيل، ومن تطابق محتوى الإعلان وصفحة الهبوط.
